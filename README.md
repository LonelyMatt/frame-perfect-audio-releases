# Frame Perfect Audio

Drop in a song and get markers on every bar, build, breakdown, chorus and drop,
each one landing on the exact video frame, for Final Cut Pro, DaVinci Resolve,
Premiere Pro and HitFilm. With an account, tell the AI what you want from your
clips and it lines them up on the beat.

## Download

Get the newest version from **[Releases](../../releases/latest)**:

| System | File |
| --- | --- |
| Windows 10 / 11 | `Frame Perfect Audio <version> setup.exe` |
| macOS 11 or newer (Apple silicon) | `Frame Perfect Audio <version>.dmg` |
| Linux | `Frame Perfect Audio <version> linux.zip` |

The download is about 400 MB: it includes the song analysis (Beat This!) so
everything runs on your own computer.

## Installing

**Windows:** run the setup. Windows may say *"Windows protected your PC"*
because the app isn't signed yet: click **More info → Run anyway**.

**macOS:** open the .dmg and drag **Frame Perfect Audio** into **Applications**.
The first time, macOS may say it's from an unidentified developer:
**right-click the app → Open → Open**. (Or System Settings → Privacy &
Security → **Open Anyway**.)

**Linux:** unzip it and run `Frame Perfect Audio/Frame Perfect Audio`.

## Your files

Your songs, clips and exports stay on your computer:

- Windows: `%LOCALAPPDATA%\Frame Perfect Audio`
- macOS: `~/Library/Application Support/Frame Perfect Audio`
- Linux: `~/.local/share/frame-perfect-audio`

Updating or uninstalling the app keeps them.
